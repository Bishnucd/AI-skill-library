# Typst Invoice Template Automation

## Description
Compiles dynamic transactional billing invoices from Typst templates with currency formatting and line items. Use when generating beautiful, modern PDF invoices with blazing-fast compile times.

## Purpose
Typst compiles in milliseconds, making it ideal for real-time PDF generation. Templating invoice calculations, line item tables, and client details produces modern, vector-sharp invoice documents.

## When to Use
- When executing typst invoice template automation in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Typst, CLI) cannot be provisioned.

## Supported Technologies
- Typst
- CLI
- Rust Engine
- PDF

## Example Use Cases
### Real-Time SaaS Billing PDF Exports
Generating on-demand customer receipt PDFs on the fly when users click "Download Invoice".

### High-Volume Billing Batches
Compiling 100,000 monthly utility invoices in minutes rather than hours.
