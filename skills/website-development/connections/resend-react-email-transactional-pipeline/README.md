# Resend React Email Transactional Pipeline

## Description
Sends dynamic transactional emails rendered with React Email components using the Resend API. Use when building maintainable, responsive transactional email templates.

## Purpose
HTML email tables are difficult to write and maintain. React Email allows developers to author email templates using modern React components, compiled to bulletproof cross-client HTML by Resend.

## When to Use
- When executing resend react email transactional pipeline in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Resend, React Email) cannot be provisioned.

## Supported Technologies
- Resend
- React Email
- Transactional Email
- Modern DX

## Example Use Cases
### Branded User Welcome & Activation Email
Delivering responsive onboarding emails with personalized action buttons that look perfect in Outlook and Gmail.

### Order Confirmation Receipt Email
Rendering itemized customer checkout invoices using reusable React table components.
