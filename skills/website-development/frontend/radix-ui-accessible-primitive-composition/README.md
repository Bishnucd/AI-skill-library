# Radix Ui Accessible Primitive Composition

## Description
Composes unstyled, accessible UI components (dropdowns, dialogs, tabs) using Radix UI primitives. Use when building bespoke design systems with guaranteed WAI-ARIA compliance.

## Purpose
Radix UI Primitives handle complex keyboard navigation, focus trapping, screen reader announcements, and portal rendering out of the box, giving developers 100% styling freedom with Tailwind.

## When to Use
- When executing radix ui accessible primitive composition in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Radix UI, Unstyled Primitives) cannot be provisioned.

## Supported Technologies
- Radix UI
- Unstyled Primitives
- Accessibility (WAI-ARIA)
- Headless UI

## Example Use Cases
### Custom Branded Dropdown Menu Component
Building a beautiful custom dropdown menu that adheres 100% to WAI-ARIA menu navigation standards.

### Accessible Accessible Popover Context Cards
Implementing hover/focus trigger popover cards with automated collision detection and repositioning.
