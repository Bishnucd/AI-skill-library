# Framer Motion Layout Page Transitions

## Description
Crafts fluid shared-element layout animations and page transitions using Framer Motion. Use when building native-app-quality microinteractions and route transitions in React.

## Purpose
Framer Motion uses GPU-accelerated transforms to animate element geometry changes automatically when adding layout or layoutId props, creating seamless shared-element transitions.

## When to Use
- When executing framer motion layout page transitions in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Framer Motion, Layout Animations) cannot be provisioned.

## Supported Technologies
- Framer Motion
- Layout Animations
- Page Transitions
- React Motion

## Example Use Cases
### E-Commerce Product Card to Modal Expansion
Morphing a thumbnail image smoothly into a full-screen gallery view on click.

### Smooth Tab Indicator Underline Animation
Gliding a visual highlight indicator smoothly beneath the active tab as users switch views.
