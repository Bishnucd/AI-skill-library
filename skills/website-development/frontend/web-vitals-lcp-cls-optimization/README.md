# Web Vitals Lcp Cls Optimization

## Description
Audits and optimizes Core Web Vitals (Largest Contentful Paint, Cumulative Layout Shift, Interaction to Next Paint). Use when optimizing web page performance for speed and SEO rankings.

## Purpose
Core Web Vitals directly determine search engine ranking and user bounce rates. Eliminating render-blocking resources, preloading hero images, and reserving layout aspect ratios achieves top scores.

## When to Use
- When executing web vitals lcp cls optimization in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Core Web Vitals, Chrome DevTools) cannot be provisioned.

## Supported Technologies
- Core Web Vitals
- Chrome DevTools
- Lighthouse
- JavaScript

## Example Use Cases
### E-commerce Conversion Speedup
Achieving sub-1.5s LCP and zero CLS on high-traffic product landing pages.

### Google SEO Ranking Boost
Passing all three Core Web Vitals thresholds to gain maximum mobile search engine visibility.
