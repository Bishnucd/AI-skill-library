# Screenplay Fountain Syntax Formatting

## Description
Formats cinematic screenplays using open-source Fountain plaintext syntax for automated scene breakdown. Use when drafting scripts that convert seamlessly to PDF, FDX, and production boards.

## Purpose
Fountain is a plaintext markup language that allows writers to draft screenplays in any text editor, converting automatically to industry-standard 12pt Courier screenplay formatting.

## When to Use
- When executing screenplay fountain syntax formatting in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Fountain Syntax, Screenwriting) cannot be provisioned.

## Supported Technologies
- Fountain Syntax
- Screenwriting
- Plaintext-to-Script
- Production Breakdown

## Example Use Cases
### Indie Film Screenplay Drafting
Writing feature film scripts in version-controlled Git repositories using lightweight Markdown-like syntax.

### Automated Scene Character Breakdown
Parsing screenplay Fountain files to automatically generate actor scheduling requirement matrices.
