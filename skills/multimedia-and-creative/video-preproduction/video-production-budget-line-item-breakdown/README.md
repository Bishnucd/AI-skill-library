# Video Production Budget Line Item Breakdown

## Description
Structures Above-The-Line (ATL) and Below-The-Line (BTL) film production budgets with contingency funds. Use when estimating commercial, corporate, and independent film production costs.

## Purpose
Production budgeting categorizes expenditures into Above-the-Line (director, writer, key cast), Below-the-Line (crew, gear, locations, catering), and post-production, adding a standard 10% contingency.

## When to Use
- When executing video production budget line item breakdown in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Production Budgeting, ATL / BTL Accounts) cannot be provisioned.

## Supported Technologies
- Production Budgeting
- ATL / BTL Accounts
- Movie Magic / Excel
- Financial Planning

### Commercial Video Client Production Estimate
Authoring a transparent $150,000 commercial production budget for corporate brand review.

### Independent Feature Film Financing Deck
Structuring a $1,200,000 indie feature budget compliant with SAG-AFTRA indie theatrical agreements.
