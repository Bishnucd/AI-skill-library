# Video Equipment Camera Package Checklist

## Description
Authors standardized camera, lighting, grip, and audio gear packages for film production shoots. Use when prepping equipment rentals and ensuring zero missing accessories on set.

## Purpose
Forgetting a single specialized cable or baseplate halts a production. Standardized camera package checklists itemize cameras, lenses, media cards, monitors, power cables, and matte boxes.

## When to Use
- When executing video equipment camera package checklist in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Camera Package, Gear Prep) cannot be provisioned.

## Supported Technologies
- Camera Package
- Gear Prep
- Equipment Rental
- Checklist Management

## Example Use Cases
### Remote Mountain Expedition Gear Prep
Packing a weatherized, redundant camera package for a 5-day backcountry documentary shoot.

### Rental House Camera Checkout Checklist
Bench-testing every lens, wireless video link, and cable at the rental house before leaving.
