# B Roll Shot List Planner

## Description
Compiles categorized B-roll shot lists with lens choices, camera movements, and location requirements. Use when planning production video shoots to ensure comprehensive B-roll coverage.

## Purpose
Editors face disaster in post-production when essential cutaway B-roll footage is missing. A comprehensive shot list plans coverage angles, establishing shots, and macro details.

## When to Use
- When executing b roll shot list planner in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Markdown, Production Planning) cannot be provisioned.

## Supported Technologies
- Markdown
- Production Planning
- CSV

## Example Use Cases
### Corporate Video Shoot Prep
Organizing 40 cutaway shots across office facilities within a single half-day shoot.

### Documentary Field Production
Ensuring camera operators capture essential atmospheric and contextual B-roll.
