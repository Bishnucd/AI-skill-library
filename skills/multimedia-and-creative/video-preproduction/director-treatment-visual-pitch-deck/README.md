# Director Treatment Visual Pitch Deck

## Description
Structures cinematic director treatment presentations with visual tone references, color palettes, and camera style rules. Use when pitching commercial and music video projects to clients.

## Purpose
Director treatments win commercial bids. They translate script ideas into a tangible visual vision, explaining camera movement, casting archetypes, color palettes, and musical tone.

## When to Use
- When executing director treatment visual pitch deck in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Director Treatment, Pitch Deck) cannot be provisioned.

## Supported Technologies
- Director Treatment
- Pitch Deck
- Visual Concept
- Commercial Production
