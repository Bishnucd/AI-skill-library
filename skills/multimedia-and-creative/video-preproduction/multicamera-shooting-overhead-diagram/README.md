# Multicamera Shooting Overhead Diagram

## Description
Designs studio multi-camera and lighting overhead floor plans with camera coverage cones. Use when planning live multi-cam broadcasts, talk shows, and sitcom stages.

## Purpose
Multi-camera shoots require precise physical camera placement to ensure cameras do not shoot each other while maintaining flattering angles. Overhead diagrams map camera positions and focal cones.

## When to Use
- When executing multicamera shooting overhead diagram in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Floor Plan Diagram, Multi-Cam Setup) cannot be provisioned.

## Supported Technologies
- Floor Plan Diagram
- Multi-Cam Setup
- Coverage Cones
- Studio Planning

## Example Use Cases
### Late Night Talk Show Studio Floor Plan
Arranging 4 studio ped cameras to cover host desk, guest couch, and musical performance stage.

### Live Esports Arena Broadcast Camera Layout
Positioning jib cameras, player POV cams, and caster desk angles in an arena stadium.
