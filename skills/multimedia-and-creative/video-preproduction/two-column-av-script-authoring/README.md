# Two Column Av Script Authoring

## Description
Structures professional two-column Audio/Visual (A/V) scripts matching visual descriptions to spoken narration. Use when scripting corporate videos, commercials, and explainer animations.

## Purpose
Standard screenplay format fails for commercial and documentary videos where visuals and audio run in parallel. A two-column A/V script aligns visual camera directions with narration timecodes.

## When to Use
- When executing two column av script authoring in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Markdown, Screenwriting Standards) cannot be provisioned.

## Supported Technologies
- Markdown
- Screenwriting Standards
- Spreadsheets

## Example Use Cases
### Product Explainer Scripting
Aligning animated UI graphic actions with voiceover explanation steps.

### Commercial Video Production
Providing clear visual and acoustic roadmaps for commercial directors and editors.
