# Location Scout Checklist Audit

## Description
Audits filming locations for ambient acoustic noise, electrical power availability, and lighting conditions. Use when scouting and approving filming locations before shoot day.

## Purpose
A visually stunning filming location is useless if airport flight paths ruin audio or insufficient circuit breakers trip under production lights. A location audit prevents disastrous shoot-day surprises.

## When to Use
- When executing location scout checklist audit in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Markdown, Acoustic Auditing) cannot be provisioned.

## Supported Technologies
- Markdown
- Acoustic Auditing
- Field Checklists

## Example Use Cases
### Commercial Location Approval
Vetting candidate interview filming locations before booking production crews.

### Permit & Insurance Compliance
Documenting municipal permit requirements and safety clearances for filming sites.
