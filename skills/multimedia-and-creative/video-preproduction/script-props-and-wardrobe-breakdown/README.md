# Script Props And Wardrobe Breakdown

## Description
Deconstructs screenplays into categorized prop, costume, vehicle, and set dressing lists. Use when creating art department breakdowns and production budget line items.

## Purpose
The 1st AD and Art Department break down scripts into color-coded elements. Tracking hand props, picture vehicles, and wardrobe changes per scene prevents missing items on shoot days.

## When to Use
- When executing script props and wardrobe breakdown in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Script Breakdown, Art Department) cannot be provisioned.

## Supported Technologies
- Script Breakdown
- Art Department
- Props Tracking
- Wardrobe Management

## Example Use Cases
### Period Drama Wardrobe Breakdown
Tracking 1920s vintage dresses, pocket watches, and period automobiles across 45 shoot scenes.

### Action Film Hero Prop Sourcing
Cataloging stunt-rubber props vs hero functional props required for intense fight choreography.
