# Talent Release Legal Agreement Authoring

## Description
Authors legally binding video and voice talent release agreements protecting intellectual property and distribution rights. Use when clearing actors, interviewees, and extras for commercial release.

## Purpose
Distributing video without signed talent releases exposes productions to injunctions and lawsuits. Standard releases grant perpetual, irrevocable, worldwide rights to likeness, voice, and performance.

## When to Use
- When executing talent release legal agreement authoring in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Legal Release Form, Media Rights) cannot be provisioned.

## Supported Technologies
- Legal Release Form
- Media Rights
- Production Clearance
- Copyright

## Example Use Cases
### Documentary Street Interview Clearance
Securing signed digital talent releases on tablets from street interviewees before filming begins.

### Voice Actor AI Training Clearance Waiver
Specifying exact usage parameters regarding commercial advertising vs AI synthetic voice cloning.
