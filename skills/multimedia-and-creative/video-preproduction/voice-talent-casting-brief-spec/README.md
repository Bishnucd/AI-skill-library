# Voice Talent Casting Brief Spec

## Description
Drafts comprehensive voice casting briefs detailing character personas, vocal tone, pacing, and audition scripts. Use when hiring professional voiceover actors for commercial projects.

## Purpose
Vague casting briefs yield mismatched audition reads. A detailed spec defines target age, accent, energy level, descriptive tone keywords (e.g. authoritative yet warm), and pronunciation guides.

## When to Use
- When executing voice talent casting brief spec in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Markdown, Casting Specifications) cannot be provisioned.

## Supported Technologies
- Markdown
- Casting Specifications
- Creative Direction

## Example Use Cases
### Commercial Voice Talent Hiring
Posting clear casting specifications on talent platforms (Voices.com, Voice123).

### Video Game Character Casting
Directing voice actors on specific character backstory, motivation, and vocal rasp.
