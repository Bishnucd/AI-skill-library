# Music Cue Sheet Licensing Breakdown

## Description
Documents background music cues with Performing Rights Organization (PRO) metadata for broadcast clearance. Use when submitting music cue sheets to ASCAP, BMI, and distributors.

## Purpose
Broadcasters cannot air films without music cue sheets. Cue sheets detail every musical composition, cue duration, usage type (background, theme, visual), and composer royalty splits.

## When to Use
- When executing music cue sheet licensing breakdown in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Music Cue Sheet, ASCAP / BMI / SESAC) cannot be provisioned.

## Supported Technologies
- Music Cue Sheet
- ASCAP / BMI / SESAC
- Music Clearance
- Licensing

### Netflix & Broadcast Film Delivery Deliverable
Submitting verified music cue sheets for an indie feature film prior to streaming platform ingestion.

Clearing sync and master rights for a licensed pop song in a national broadcast commercial.
