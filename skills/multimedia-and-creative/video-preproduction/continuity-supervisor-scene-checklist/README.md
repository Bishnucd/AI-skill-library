# Continuity Supervisor Scene Checklist

## Description
Tracks actor wardrobe, hair, props, and eyelines across non-sequential film takes to prevent continuity errors. Use when supervising script continuity on set.

## Purpose
Films are shot out of sequence. A glass half-empty in Take 1 must not be full in Take 2. Script supervisors photograph actor state, log action timing, and mark lined scripts for editors.

## When to Use
- When executing continuity supervisor scene checklist in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Script Continuity, Lined Script) cannot be provisioned.

## Supported Technologies
- Script Continuity
- Lined Script
- Eyeline Tracking
- Film Production

## Example Use Cases
### Dinner Scene Prop Continuity Supervision
Ensuring food levels on plates and drink levels in glasses remain consistent across 12 camera setups.

### Action Fight Eyeline Direction Verification
Verifying that two actors looking at each other maintain complementary screen-left and screen-right eyelines.

1. Review the operational workflow defined in `SKILL.md`.
2. Ensure runtime dependencies (Script Continuity) are configured in the host environment.
3. Execute the workflow steps sequentially, validating intermediate outputs.
