# Three Point Lighting Ratio Setup Spec

## Description
Designs key, fill, and backlight lighting ratios (1:2, 1:4, 1:8) for cinematic interview moods and dramatic tone. Use when authoring lighting design diagrams for cinematographers and gaffers.

## Purpose
Three-point lighting defines visual mood. Low-contrast corporate interviews use a gentle 1:2 key-to-fill ratio, while film noir and dramatic thrillers use high-contrast 1:8 ratios with deep shadows.

## When to Use
- When executing three point lighting ratio setup spec in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Lighting Design, Lighting Ratios) cannot be provisioned.

## Supported Technologies
- Lighting Design
- Lighting Ratios
- Cinematography
- Grip and Electric

## Example Use Cases
### Corporate Executive Interview Lighting Plan
Designing a soft, flattering 1:2 lighting setup with large diffusion frames for executive profiles.

### Dramatic Crime Documentary Interview Mood
Authoring a moody 1:8 Rembrandt lighting setup casting dramatic triangular cheek highlights.
