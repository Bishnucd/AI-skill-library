# Visual Storyboard Animatic Sequencing

## Description
Assembles sequential storyboard sketches into timed animatic video reels with scratch voiceover and audio beds. Use when pre-visualizing scene pacing, camera cuts, and story beats.

## Purpose
Filming without pacing validation risks costly reshoots. Animatics sequence storyboard drawings onto a video timeline with rough dialogue and sound effects to test pacing before camera rolls.

## When to Use
- When executing visual storyboard animatic sequencing in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Animatic Sequencing, Pre-Visualization) cannot be provisioned.

## Supported Technologies
- Animatic Sequencing
- Pre-Visualization
- Storyboarding
- FFmpeg / Python

## Example Use Cases
### TV Commercial Pacing Pre-Visualization
Validating that a 30-second commercial script fits the time limit with comfortable visual breathing room.

### Animated Feature Film Story Reel
Testing comedic timing and emotional character beats on storyboard drawings before beginning 3D animation.
