# Focus Stacking Depth Of Field Fusion

## Description
Fuses a focus-bracketed series of macro photographs into a single composite image with infinite depth of field. Use when photographing micro-electronics, jewelry, and insects.

## Purpose
Macro lenses have microscopic depth of field, rendering only a fraction of millimeter in focus. Focus stacking captures slices across focal planes and selects the sharpest pixels for each region.

## When to Use
- When executing focus stacking depth of field fusion in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Focus Stacking, Laplacian Pyramids) cannot be provisioned.

## Supported Technologies
- Focus Stacking
- Laplacian Pyramids
- OpenCV
- Macro Photography

## Example Use Cases
### Micro-Electronic Circuit Board Inspection
Producing razor-sharp macro images of microscopic solder joints across high-component PCB boards.

### Luxury Watch Dial Catalog Photography
Focusing on both the front watch hands and the recessed background dial markers simultaneously.
