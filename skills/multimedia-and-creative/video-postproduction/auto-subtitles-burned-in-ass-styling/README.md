# Auto Subtitles Burned In Ass Styling

## Description
Compiles transcribed subtitle files into styled Advanced SubStation Alpha (.ass) scripts and burns them into video. Use when creating hardcoded social media video captions with custom fonts.

## Purpose
Social video feeds mute audio by default. Hardcoding animated, styled captions directly into the video canvas using the ASS format guarantees maximum viewer engagement and retention.

## When to Use
- When executing auto subtitles burned in ass styling in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (FFmpeg, ASS Subtitle Format) cannot be provisioned.

## Supported Technologies
- FFmpeg
- ASS Subtitle Format
- Node.js / Python
- Typography

## Example Use Cases
### Social Video Caption Burn-In
Hardcoding stylized neon karaoke subtitles into vertical short-form marketing videos.

### Multi-Language Hardsubbing
Burning localized foreign subtitles into instructional training videos.
