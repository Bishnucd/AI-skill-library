# Vertical Video Aspect Reframe 9 16

## Description
Reframes horizontal 16:9 landscape video footage into 9:16 vertical video using dynamic pan-and-scan and background blur. Use when repurposing horizontal video for mobile vertical platforms.

## Purpose
Repurposing landscape video for smartphones requires smart framing. Either pan-and-scan tracks the primary subject, or the 16:9 clip is centered over a scaled, blurred background canvas.

## When to Use
- When executing vertical video aspect reframe 9 16 in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (FFmpeg, OpenCV) cannot be provisioned.

## Supported Technologies
- FFmpeg
- OpenCV
- Bash / Python
- Aspect Ratios

## Example Use Cases
### Podcast Video Short Repurposing
Transforming horizontal studio interview cameras into vertical TikTok video clips.

### Webinar Highlight Clips
Adapting wide desktop screen shares into readable mobile video snippets.
