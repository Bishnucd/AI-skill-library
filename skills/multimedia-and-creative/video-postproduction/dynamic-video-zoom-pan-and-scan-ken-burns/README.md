# Dynamic Video Zoom Pan And Scan Ken Burns

## Description
Animates smooth Ken Burns camera zooms, pans, and drifts across high-resolution still photographs using FFmpeg zoompan. Use when producing documentary video sequences from archival photos.

## Purpose
Static photos feel flat in video productions. The Ken Burns effect applies slow mathematical camera zooms and panning trajectories across high-res photos to create emotional visual movement.

## When to Use
- When executing dynamic video zoom pan and scan ken burns in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Ken Burns Effect, FFmpeg zoompan) cannot be provisioned.

## Supported Technologies
- Ken Burns Effect
- FFmpeg zoompan
- Motion Graphics
- Documentary Editing

## Example Use Cases
### Historical Documentary Archival Sequence
Slowly zooming into the face of a historical figure in an antique 1860s daguerreotype photo.

Panning across wide living room photography to create an animated video tour for buyers.
