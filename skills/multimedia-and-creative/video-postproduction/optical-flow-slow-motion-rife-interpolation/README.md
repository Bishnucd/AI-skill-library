# Optical Flow Slow Motion Rife Interpolation

## Description
Generates ultra-smooth slow motion video using RIFE neural optical flow frame interpolation. Use when turning 24fps/30fps camera clips into cinematic 60fps/120fps slow-motion.

## Purpose
Standard frame blending causes ghosting, and frame repeating causes stutter. RIFE calculates bidirectional optical flow vectors to synthesize intermediate frames with pristine clarity.

## When to Use
- When executing optical flow slow motion rife interpolation in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (RIFE, Optical Flow) cannot be provisioned.

## Supported Technologies
- RIFE
- Optical Flow
- Frame Interpolation
- Slow Motion
