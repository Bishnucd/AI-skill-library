# Flux Midjourney Prompt Crafting

## Description
Structures descriptive prompts with camera angles, lighting conditions, and negative modifiers for diffusion models. Use when generating high-fidelity photorealistic imagery with Midjourney or Flux.

## Purpose
Diffusion models reward specific cinematography parameters (focal length, lighting, film stock) over generic buzzwords like "photorealistic". Structured prompt syntax ensures reproducible quality.

## When to Use
- When executing flux midjourney prompt crafting in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Prompt Engineering, Midjourney v6) cannot be provisioned.

## Supported Technologies
- Prompt Engineering
- Midjourney v6
- Flux.1
- Diffusion Models

## Example Use Cases
### Advertising Visual Concepting
Creating commercial-grade product hero shots for digital marketing campaigns.

### Architectural Visualization
Generating exterior renderings with realistic natural illumination and material textures.

1. Review the operational workflow defined in `SKILL.md`.
