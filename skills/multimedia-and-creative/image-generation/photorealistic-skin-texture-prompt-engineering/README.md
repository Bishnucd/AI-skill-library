# Photorealistic Skin Texture Prompt Engineering

## Description
Prompts realistic skin micro-textures, subsurface scattering, and natural pores without synthetic plastic sheen. Use when generating high-fidelity human portraits and character art.

## Purpose
AI portrait generation often defaults to artificial, plastic-looking airbrushed skin. Engineering prompts with optical camera and biological lighting cues produces natural human skin textures.

## When to Use
- When executing photorealistic skin texture prompt engineering in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Subsurface Scattering, Micro-Textures) cannot be provisioned.

## Supported Technologies
- Subsurface Scattering
- Micro-Textures
- Photorealism
- Prompt Engineering

## Example Use Cases
### Commercial Fashion Advertising Portraits
Generating lifelike diverse models with realistic skin freckles, pores, and natural lighting.

### Historical Period Character Dramatization
Depicting weathered historical figures with realistic facial wrinkles, sun damage, and dirt textures.
