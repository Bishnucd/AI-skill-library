# Composition Grid Rule Of Thirds Framing

## Description
Structures image composition using classical rule of thirds, leading lines, and golden ratio framing. Use when directing cinematic photography and editorial compositions.

## Purpose
AI models tend to place subjects directly in the dead center of the frame. Applying compositional language and aspect ratio anchors shifts visual weight to create dynamic, cinematic balance.

## When to Use
- When executing composition grid rule of thirds framing in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Rule of Thirds, Golden Ratio) cannot be provisioned.

## Supported Technologies
- Rule of Thirds
- Golden Ratio
- Cinematography
- Compositional Prompting

## Example Use Cases
### Cinematic Movie Poster Key Art
Positioning a lone hero on the bottom-right intersection gazing up at a looming mountain citadel.

### Editorial Magazine Hero Banner
Leaving the left two-thirds open for text typography while staging the model on the right third.
