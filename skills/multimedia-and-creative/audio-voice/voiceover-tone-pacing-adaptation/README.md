# Voiceover Tone Pacing Adaptation

## Description
Adapts voiceover speaking rate and pause cadence to match target genre pacing (e.g., corporate vs documentary). Use when tailoring voiceover pacing to visual video scene transitions.

## Purpose
Corporate promos require brisk pacing (150–160 WPM), while meditative documentaries demand deliberate pacing (110–120 WPM). Pacing adaptation calculates syllable density and adjusts cadence.

## When to Use
- When executing voiceover tone pacing adaptation in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Pacing Adaptation, Syllable Counting) cannot be provisioned.

## Supported Technologies
- Pacing Adaptation
- Syllable Counting
- Prosody Tuning
- Voiceover Direction

## Example Use Cases
### Fast-Paced TikTok Video Ad Voiceover
Synthesizing punchy, energetic narration at 165 WPM to maintain fast mobile viewer engagement.

### Relaxing Sleep Meditation Narration
Slowing speech rate to 105 WPM with elongated 2-second breathing pauses between guidance cues.
