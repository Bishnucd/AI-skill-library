# Criterion Rust Micro Benchmark Harness

## Description
Measures CPU clock cycles, execution latency, and throughput of algorithms using Rust Criterion.rs. Use when preventing performance regressions in high-speed systems programming.

## Purpose
Criterion.rs provides statistics-driven microbenchmarking for Rust code, analyzing execution time distributions, detecting regressions, and generating interactive HTML graphs.

## When to Use
- When executing criterion rust micro benchmark harness in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Criterion.rs, Rust) cannot be provisioned.

## Supported Technologies
- Criterion.rs
- Rust
- Microbenchmarking
- Performance Engineering

## Example Use Cases
### High-Performance JSON Parser Optimization
Measuring nanosecond performance improvements when rewriting SIMD string scanning logic.

### Cryptographic Hashing Algorithm Benchmarking
Verifying that a cryptographic hash function executes in constant time regardless of input pattern.
