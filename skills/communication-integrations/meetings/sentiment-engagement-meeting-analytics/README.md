# Sentiment Engagement Meeting Analytics

## Description
Measures speaker talk-time ratios, interruption frequencies, and sentiment trends in meeting recordings. Use when coaching remote leadership and improving team meeting inclusivity.

## Purpose
Dominating conversations or high interruption rates stifle team collaboration. Quantifying talk-time distribution and emotional sentiment curves provides objective feedback to meeting facilitators.

## When to Use
- When executing sentiment engagement meeting analytics in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Audio Analytics, VADER Sentiment) cannot be provisioned.

## Supported Technologies
- Audio Analytics
- VADER Sentiment
- Python
- Pandas

## Example Use Cases
### Executive Coaching Telemetry
Helping managers ensure equitable speaking time across distributed remote team members.

### Sales Pitch Effectiveness
Analyzing talk-to-listen ratios during sales discovery calls (targeting 40% talk / 60% listen).
