# Meeting Cost Ticker Calculator

## Description
Calculates real-time cumulative meeting dollar costs based on participant count, duration, and average salaries. Use when driving meeting brevity and eliminating unnecessary large meetings.

## Purpose
Large meetings waste enormous corporate payroll. Displaying a running dollar counter ($/minute) based on attendee average hourly rates encourages organizers to stay focused and end early.

## When to Use
- When executing meeting cost ticker calculator in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Cost Calculation Engine, Salary Aggregates) cannot be provisioned.

## Supported Technologies
- Cost Calculation Engine
- Salary Aggregates
- JavaScript
- Meeting Analytics

## Example Use Cases
### Meeting Culture Optimization
Encouraging organizers to invite only essential participants to expensive executive reviews.

### Engineering Meeting Audit
Quantifying engineering hours spent in recurring meetings to defend focused coding time.
