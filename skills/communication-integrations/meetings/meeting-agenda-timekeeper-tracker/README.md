# Meeting Agenda Timekeeper Tracker

## Description
Tracks agenda items, allocated time limits, and real-time discussion progress during collaborative meetings. Use when keeping complex team meetings on schedule and focused on outcomes.

## Purpose
Unstructured meetings frequently run over time without reaching decisions. An agenda timekeeper enforces timeboxed topic slots, tracks speaker time, and logs immediate action decisions.

## When to Use
- When executing meeting agenda timekeeper tracker in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Markdown, Timer Utilities) cannot be provisioned.

## Supported Technologies
- Markdown
- Timer Utilities
- Websockets
- TypeScript

## Example Use Cases
### Architecture Review Meetings
Keeping deep-dive technical evaluations focused within scheduled meeting windows.

### Executive Board Updates
Ensuring critical governance and financial reviews fit strictly within limited executive time.
