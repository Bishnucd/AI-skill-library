# Streamlit Analytics Dashboard Layout

## Description
Builds interactive analytics web applications using Python Streamlit with caching and KPI metric cards. Use when deploying executive data apps and machine learning model explorers.

## Purpose
Streamlit turns Python data scripts into shareable interactive web applications with native state management, st.cache_data performance caching, and reactive sidebar filters.

## When to Use
- When executing streamlit analytics dashboard layout in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Streamlit, Python) cannot be provisioned.

## Supported Technologies
- Streamlit
- Python
- KPI Metrics
- Web Dashboard

## Example Use Cases
### Executive Sales Pipeline Dashboard
Providing sales leaders with interactive regional quota vs revenue exploration.

### Fraud Model Prediction Inspector
Allowing compliance analysts to adjust scoring thresholds and view real-time false positives.

## Usage Instructions
1. Review the operational workflow defined in `SKILL.md`.
2. Ensure runtime dependencies (Streamlit) are configured in the host environment.
3. Execute the workflow steps sequentially, validating intermediate outputs.
4. Verify the final generated artifact against declared acceptance criteria.
