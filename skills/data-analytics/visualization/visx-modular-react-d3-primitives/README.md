# Visx Modular React D3 Primitives

## Description
Constructs custom, type-safe React chart components by composing low-level Airbnb Visx D3 primitives. Use when building bespoke design-system chart libraries in React.

## Purpose
Visx combines the mathematical power of D3 layout calculations with React declarative DOM rendering, producing lightweight, unopinionated, fully customizable charting components.

## When to Use
- When executing visx modular react d3 primitives in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Visx, D3.js) cannot be provisioned.

## Supported Technologies
- Visx
- D3.js
- React
- TypeScript

## Example Use Cases
### Bespoke Corporate Design System Charts
Building branded line and bar chart components matching exact typography and theme tokens.

### Interactive Stepper Funnel Graphic
Constructing custom polygon funnel visualization for user onboarding drop-off stages.
