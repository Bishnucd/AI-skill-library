# Altair Declarative Python Grammar

## Description
Authors declarative statistical visualizations in Python using Altair, compiled directly to Vega-Lite JSON. Use when creating repeatable, publication-ready statistical plots.

## Purpose
Altair is a declarative statistical visualization library for Python based on Vega-Lite. It provides a clean, concise syntax that maps dataframe columns directly to visual encoding channels.

## When to Use
- When executing altair declarative python grammar in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Altair, Vega-Lite) cannot be provisioned.

## Supported Technologies
- Altair
- Vega-Lite
- Python
- Declarative Visualization

## Example Use Cases
### Interactive Linked Scatter-Histogram
Brushing points in a scatter plot to dynamically highlight corresponding histogram bins.

### Academic Research Figure Generation
Exporting reproducible high-resolution vector PDF plots for journal manuscript submission.
