# Glossary Taxonomy Domain Terminology

## Description
Authors standardized ubiquitous language glossaries to unify terminology across technical documentation. Use when eliminating ambiguous, conflicting terms across product teams.

## Purpose
When engineers say "Tenant", marketing says "Workspace", and support says "Organization", customers get confused. A central technical glossary defines canonical terms and deprecates synonyms.

## When to Use
- When executing glossary taxonomy domain terminology in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Glossary Authoring, Taxonomy) cannot be provisioned.

### Fintech Domain Terminology Standardization
Formally defining the exact technical distinction between a "Transaction", "Settlement", and "Payout".

### Multi-Product Cloud Suite Glossary
Aligning vocabulary across 5 acquired SaaS products into a unified enterprise terminology taxonomy.
