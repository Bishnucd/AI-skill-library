# Form Input Validation Microcopy

## Description
Designs contextual inline form validation microcopy, error states, and helpful recovery guidance. Use when crafting intuitive, frustration-free form validation experiences.

## Purpose
Generic error messages ("Invalid input") frustrate users and trigger form abandonment. Clear microcopy explains exactly what is wrong and how to fix it in concise, non-accusatory language.

## When to Use
- When executing form input validation microcopy in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (UX Writing, Microcopy) cannot be provisioned.

## Supported Technologies
- UX Writing
- Microcopy
- Form Design
- Accessibility

## Example Use Cases
### Checkout Funnel Optimization
Reducing credit card and shipping address submission errors to boost checkout conversion.

### Registration Flow Polish
Guiding users smoothly through complex password creation and username validation.
