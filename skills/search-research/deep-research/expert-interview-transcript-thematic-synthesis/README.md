# Expert Interview Transcript Thematic Synthesis

## Description
Codes qualitative transcripts and synthesizes industry expert calls using systematic thematic analysis. Use when extracting actionable market intelligence from expert network interviews.

## Purpose
Interviewing former executives provides deep insights, but subjective bias is common. Applying thematic analysis codes interview transcripts into verified themes, validating claims across multiple calls.

## When to Use
- When executing expert interview transcript thematic synthesis in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Thematic Analysis, Qualitative Coding) cannot be provisioned.

## Supported Technologies
- Thematic Analysis
- Qualitative Coding
- Expert Interviews
- Market Research

## Example Use Cases
### Private Equity Software Buyout Diligence
Synthesizing 10 expert calls with former customers to validate vendor churn risk and switching friction.

### Enterprise Cloud Migration Market Trends
Extracting key themes from CIO interviews regarding multi-cloud cost repatriation strategies.
