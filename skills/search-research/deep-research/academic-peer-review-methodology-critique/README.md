# Academic Peer Review Methodology Critique

## Description
Critiques academic research methodology, statistical power, p-hacking risks, and sample bias validity. Use when evaluating scientific claims before basing corporate strategy on research papers.

## Purpose
Many published studies fail replication due to small sample sizes and post-hoc data slicing (p-hacking). Systematic critique evaluates experimental controls, statistical power, and potential researcher bias.

## When to Use
- When executing academic peer review methodology critique in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Methodology Critique, Statistical Power Analysis) cannot be provisioned.

## Supported Technologies
- Methodology Critique
- Statistical Power Analysis
- P-Hacking Detection
- Academic Rigor

## Example Use Cases
### AI Benchmark Benchmark Leakage Audit
Evaluating whether a newly published state-of-the-art LLM paper accidentally included test data in training sets.

### Biotech Clinical Trial Data Verification
Auditing phase II oncology trial methodology to verify that reported survival benefits are statistically robust.
