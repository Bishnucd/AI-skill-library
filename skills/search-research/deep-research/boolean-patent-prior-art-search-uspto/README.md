# Boolean Patent Prior Art Search Uspto

## Description
Constructs comprehensive Boolean patent search queries across USPTO, EPO, and Google Patents databases. Use when establishing patentability and uncovering prior art before patent filing.

## Purpose
Patent searches require mastering Cooperative Patent Classification (CPC) codes and Boolean proximity operators (ADJ, NEAR) across title, abstract, and claims to uncover obscure prior art.

## When to Use
- When executing boolean patent prior art search uspto in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Patent Search, Boolean Queries) cannot be provisioned.

## Supported Technologies
- Patent Search
- Boolean Queries
- CPC Classification
- Prior Art

### AI Algorithm Patent Prior Art Clearance
Searching 30 years of patent literature to confirm novelty of a new vector quantization algorithm.

Verifying that a newly designed medical device does not infringe active competitor patents.
