# Expert Interview Synthesis Summary

## Description
Synthesizes qualitative customer and domain expert interview transcripts into thematic affinity clusters. Use when analyzing user research, stakeholder interviews, and qualitative feedback.

## Purpose
Raw qualitative interviews yield hundreds of pages of unstructured dialogue. Thematic analysis extracts verbatim quotes, tags recurring pain points, and clusters findings into strategic themes.

## When to Use
- When executing expert interview synthesis summary in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Thematic Analysis, Affinity Diagramming) cannot be provisioned.

## Supported Technologies
- Thematic Analysis
- Affinity Diagramming
- Qualitative Research
- Markdown

## Example Use Cases
### Product Discovery Synthesis
Extracting key takeaways from 20 user discovery calls to guide feature roadmaps.

### Enterprise Stakeholder Analysis
Synthesizing internal executive interviews into a unified digital transformation strategy.
