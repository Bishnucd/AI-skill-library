# Foia Public Records Request Crafting

## Description
Drafts precise, legally compliant Freedom of Information Act (FOIA) public record requests to government agencies. Use when obtaining government contracts, inspection reports, and official emails.

## Purpose
Vague FOIA requests are routinely denied under exemption rules. Crafting precise requests targeting specific agency offices, date ranges, and document titles dramatically accelerates disclosure.

## When to Use
- When executing foia public records request crafting in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (FOIA Requests, Public Records) cannot be provisioned.

## Supported Technologies
- FOIA Requests
- Public Records
- Investigative Research
- Government Compliance

## Example Use Cases
### Federal Defense Contract Award Investigation
Obtaining unclassified statements of work and vendor bidding evaluation scorecards for DoD software contracts.

### Municipal Environmental Inspection Audit
Acquiring local city water quality testing laboratory reports following industrial chemical spills.

## Usage Instructions
1. Review the operational workflow defined in `SKILL.md`.
2. Ensure runtime dependencies (FOIA Requests) are configured in the host environment.
3. Execute the workflow steps sequentially, validating intermediate outputs.
4. Verify the final generated artifact against declared acceptance criteria.
