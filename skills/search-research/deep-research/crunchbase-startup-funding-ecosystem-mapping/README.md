# Crunchbase Startup Funding Ecosystem Mapping

## Description
Maps venture funding rounds, competitor cap tables, and investor syndicates using Crunchbase and PitchBook data. Use when analyzing market investment trends and competitor capitalization.

## Purpose
Tracking capital flows reveals market momentum. Analyzing round sizes, lead investors, valuations, and founding dates identifies emerging category leaders and well-capitalized competitor threats.

## When to Use
- When executing crunchbase startup funding ecosystem mapping in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Crunchbase API, Venture Capital Data) cannot be provisioned.

## Supported Technologies
- Crunchbase API
- Venture Capital Data
- Ecosystem Mapping
- Market Research

## Example Use Cases
### Fintech Sector Capital Inflow Analysis
Mapping $500M of early-stage venture funding across 25 cross-border B2B payment startups.

### Competitor Cash Runway Assessment
Evaluating competitor funding history to estimate burn rate and predict upcoming fundraising timing.
