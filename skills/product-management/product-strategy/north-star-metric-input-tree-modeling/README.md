# North Star Metric Input Tree Modeling

## Description
Constructs a North Star Metric hierarchy connecting high-level customer value to input levers and engineering KPIs. Use when aligning cross-functional teams around sustained product growth.

## Purpose
A North Star Metric captures the moment customer value is delivered and sustainable revenue is generated. Breaking it down into Breadth, Depth, Frequency, and Efficiency creates clear team roadmaps.

## When to Use
- When executing north star metric input tree modeling in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (North Star Metric, Input Metrics Tree) cannot be provisioned.

## Supported Technologies
- North Star Metric
- Input Metrics Tree
- Growth Modeling
- Product Analytics

## Example Use Cases
### Collab Workspace North Star Alignment
Establishing "Weekly Active Co-Editing Users" as the North Star with template discovery as an input lever.

### Ride-Share Marketplace Balancing
Connecting "Completed Safe Rides per Week" to rider activation speed and driver dispatch efficiency.
