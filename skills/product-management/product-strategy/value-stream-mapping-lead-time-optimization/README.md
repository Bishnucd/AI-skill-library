# Value Stream Mapping Lead Time Optimization

## Description
Maps software delivery value streams to identify organizational wait times, handoffs, and process bottlenecks. Use when reducing feature idea-to-production deployment cycle times.

## Purpose
Value Stream Mapping charts the complete lifecycle of a feature from customer request to production release, separating active value-add processing time from wasteful wait states and queue delays.

## When to Use
- When executing value stream mapping lead time optimization in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Value Stream Mapping (VSM), Lean Software Delivery) cannot be provisioned.

## Supported Technologies
- Value Stream Mapping (VSM)
- Lean Software Delivery
- Lead Time Optimization
- DORA Metrics

## Example Use Cases
### Enterprise Release Cycle Acceleration
Reducing feature lead time from 6 weeks to 4 days by automating compliance approval gates.

### Cross-Functional Team Hand-off Reduction
Eliminating a 10-day architectural review queue by establishing self-service guardrails.
