# Opportunity Solution Tree Ost Mapping

## Description
Maps customer problems to business outcomes and experimental solutions using Teresa Torres Opportunity Solution Trees (OST). Use when aligning product discovery around continuous outcomes.

## Purpose
OST structures discovery by anchoring on a single desired business outcome, mapping customer pain points as branches (opportunities), and attaching multiple solution experiments to each opportunity.

## When to Use
- When executing opportunity solution tree ost mapping in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Opportunity Solution Tree (OST), Continuous Discovery) cannot be provisioned.

## Supported Technologies
- Opportunity Solution Tree (OST)
- Continuous Discovery
- Product Strategy
- Outcome-Driven

## Example Use Cases
### SaaS Onboarding Drop-Off Discovery
Connecting user onboarding abandonment pain points to rapid interactive checklist experiments.

### Fintech Mobile App Re-Engagement
Mapping user anxiety around monthly budgeting to automated spending insight feature concepts.
