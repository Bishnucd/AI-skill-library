# Jobs To Be Done Jtbd Interview Framework

## Description
Uncovers functional, emotional, and social customer struggles using Clayton Christensen Jobs-to-be-Done (JTBD) interview techniques. Use when discovering why customers switch products.

## Purpose
Customers do not buy products; they hire them to make progress in specific circumstances. The JTBD switch interview analyzes the Four Forces: Push of present situation, Pull of new solution, Anxiety, and Habit.

## When to Use
- When executing jobs to be done jtbd interview framework in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Jobs to be Done (JTBD), Switch Interviews) cannot be provisioned.

## Supported Technologies
- Jobs to be Done (JTBD)
- Switch Interviews
- Four Forces of Progress
- Customer Research

## Example Use Cases
### B2B CRM Replacement Switch Interview
Discovering that teams switched not for fancy features, but to eliminate 2-hour Friday spreadsheet reconciliations.

### Consumer Fitness Subscription Churn Discovery
Learning that users cancel gym apps because complex onboarding creates guilt and anxiety.
