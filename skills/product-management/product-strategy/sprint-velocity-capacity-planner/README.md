# Sprint Velocity Capacity Planner

## Description
Calculates agile team sprint capacity, historical velocity rolling averages, and load balancing. Use when planning realistic sprint workloads and preventing team burnout.

## Purpose
Overcommitting in sprint planning causes incomplete deliverables and team morale collapse. Factoring team PTO, on-call duties, and rolling velocity averages establishes sustainable sprint commitments.

## When to Use
- When executing sprint velocity capacity planner in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Agile / Scrum, Story Points) cannot be provisioned.

## Supported Technologies
- Agile / Scrum
- Story Points
- Jira / Linear
- Spreadsheets

## Example Use Cases
### Sprint Commitment Planning
Preventing chronic sprint spillover by calibrating backlog pull to realistic capacity.

### Release Date Forecasting
Forecasting release milestone dates based on empirical velocity confidence intervals.
