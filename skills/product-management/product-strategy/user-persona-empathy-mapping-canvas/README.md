# User Persona Empathy Mapping Canvas

## Description
Captures what target users say, think, do, and feel during workflow tasks using Empathy Mapping canvases. Use when building deep team empathy and eliminating subjective assumptions.

## Purpose
An Empathy Map synthesizes qualitative user observations into four quadrants (Says, Thinks, Does, Feels), helping product teams move beyond demographic stereotypes to understand cognitive reality.

## When to Use
- When executing user persona empathy mapping canvas in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Empathy Mapping, User Persona) cannot be provisioned.

## Supported Technologies
- Empathy Mapping
- User Persona
- Design Thinking
- Qualitative Research

## Example Use Cases
### DevOps Platform Persona Development
Documenting the cognitive overload and alert fatigue experienced by site reliability engineers during on-call shifts.

### Small Business Accounting App Empathy Canvas
Capturing the imposter syndrome and anxiety independent contractors feel during quarterly tax filings.
