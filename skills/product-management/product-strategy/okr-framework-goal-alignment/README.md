# Okr Framework Goal Alignment

## Description
Authors measurable Objectives and Key Results (OKRs) with leading indicators and metric targets. Use when aligning product engineering teams around strategic quarterly outcomes.

## Purpose
Vague goals produce misaligned engineering effort. Effective OKRs pair ambitious, qualitative Objectives with 3-5 quantitative Key Results measured by leading indicators rather than output checklists.

## When to Use
- When executing okr framework goal alignment in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (OKRs, Markdown) cannot be provisioned.

## Supported Technologies
- OKRs
- Markdown
- Product Strategy
- Spreadsheets

## Example Use Cases
### Quarterly Product Planning
Setting aligned engineering, product, and design goals for the upcoming quarter.

### Company Strategy Cascading
Translating executive board annual objectives into actionable team-level product initiatives.

## Usage Instructions
1. Review the operational workflow defined in `SKILL.md`.
2. Ensure runtime dependencies (OKRs) are configured in the host environment.
3. Execute the workflow steps sequentially, validating intermediate outputs.
4. Verify the final generated artifact against declared acceptance criteria.
