# Rfp Requirements Matrix Parsing

## Description
Parses complex Request for Proposal (RFP) documents into structured compliance matrices and evaluation scorecards. Use when preparing competitive bidding responses for enterprise tenders.

## Purpose
Enterprise RFPs span hundreds of pages with mandatory technical, legal, and security requirements. Extracting requirements into a traceability matrix prevents disqualification and guides proposal drafting.

## When to Use
- When executing rfp requirements matrix parsing in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Markdown, Python) cannot be provisioned.

## Supported Technologies
- Markdown
- Python
- Spreadsheets
- NLP

## Example Use Cases
### Enterprise Tender Response
Accelerating response time for government or Fortune 500 procurement RFPs.

### Product Gap Assessment
Identifying missing product features requested in customer prospect tenders.

## Usage Instructions
1. Review the operational workflow defined in `SKILL.md`.
