# Reseller Channel Partner Agreement Spec

## Description
Structures channel reseller and value-added partner agreements with wholesale discounts and referral commissions. Use when establishing commercial distribution partnerships.

## Purpose
Scaling sales through partner channels requires clear agreements defining distributor wholesale discount tiers (e.g. 20-40%), deal registration rules, co-marketing funds, and direct sales conflict resolution.

## When to Use
- When executing reseller channel partner agreement spec in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Channel Sales, Reseller Agreements) cannot be provisioned.

## Supported Technologies
- Channel Sales
- Reseller Agreements
- Partner Margins
- Markdown

## Example Use Cases
### Global Channel Partner Program
Recruiting regional system integrators to resell enterprise SaaS software in foreign markets.

### Technology Referral Agreements
Formalizing referral commission structures with complementary software vendors.

1. Review the operational workflow defined in `SKILL.md`.
