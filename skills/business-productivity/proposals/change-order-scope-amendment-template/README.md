# Change Order Scope Amendment Template

## Description
Drafts formal Change Orders detailing scope adjustments, budget deltas, and revised project delivery timelines. Use when managing project scope creep and commercial contract amendments.

## Purpose
Unmanaged scope creep destroys project profitability. A formal Change Order clearly documents requested changes, cost impact, timeline revisions, and requires mutual executive signatures before work starts.

## When to Use
- When executing change order scope amendment template in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Change Orders, Scope Management) cannot be provisioned.

## Supported Technologies
- Change Orders
- Scope Management
- Contracts
- Markdown

## Example Use Cases
### Client Scope Creep Management
Formally pricing new feature requests that fall outside the original contracted scope.

### Timeline Extension Agreements
Adjusting project deadlines when client dependency delays hold up engineering progress.
