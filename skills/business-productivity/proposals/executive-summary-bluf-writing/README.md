# Executive Summary Bluf Writing

## Description
Authors high-impact Bottom Line Up Front (BLUF) executive summaries for commercial proposals and business cases. Use when pitching complex initiatives to time-constrained executive decision makers.

## Purpose
Executives rarely read 50-page proposals. A BLUF executive summary delivers the core business challenge, proposed solution, financial ROI, and requested decision in a single compelling page.

## When to Use
- When executing executive summary bluf writing in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (BLUF Methodology, Executive Communications) cannot be provisioned.

## Supported Technologies
- BLUF Methodology
- Executive Communications
- Markdown

## Example Use Cases
### Enterprise Proposal Opening
Capturing C-suite executive interest on the first page of a multimillion-dollar proposal.

### Capital Expenditure Requests
Securing executive board approval for new cloud infrastructure investments.

## Usage Instructions
1. Review the operational workflow defined in `SKILL.md`.
2. Ensure runtime dependencies (BLUF Methodology) are configured in the host environment.
3. Execute the workflow steps sequentially, validating intermediate outputs.
4. Verify the final generated artifact against declared acceptance criteria.
