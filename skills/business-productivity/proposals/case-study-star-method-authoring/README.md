# Case Study Star Method Authoring

## Description
Authors persuasive client case studies following the STAR methodology (Situation, Task, Action, Result). Use when crafting proof points and customer success stories for proposals.

## Purpose
Prospects believe past results over sales promises. The STAR framework structures case studies into dramatic customer challenges, specific engineering interventions, and audited numeric ROI.

## When to Use
- When executing case study star method authoring in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (STAR Methodology, Marketing Writing) cannot be provisioned.

## Supported Technologies
- STAR Methodology
- Marketing Writing
- Customer Proof
- Markdown

## Example Use Cases
### Proposal Proof-Point Insertion
Embedding relevant customer success stories into competitive bidding submissions.

### Website Customer Stories
Publishing polished marketing case studies highlighting enterprise client transformations.

## Usage Instructions
1. Review the operational workflow defined in `SKILL.md`.
2. Ensure runtime dependencies (STAR Methodology) are configured in the host environment.
3. Execute the workflow steps sequentially, validating intermediate outputs.
4. Verify the final generated artifact against declared acceptance criteria.
