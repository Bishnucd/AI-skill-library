# Proposal Win Themes Differentiator Matrix

## Description
Structures proposal win themes linking customer pain points to unique organizational discriminators. Use when drafting persuasive, customer-centric proposals that outperform competitors.

## Purpose
Proposals fail when they list capabilities without connecting them to customer benefit. Shipley win themes pair a customer hot button with a unique company discriminator and quantifiable proof.

## When to Use
- When executing proposal win themes differentiator matrix in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Shipley Proposal Method, Win Themes) cannot be provisioned.

## Supported Technologies
- Shipley Proposal Method
- Win Themes
- Competitive Strategy
- Markdown

## Example Use Cases
### Competitive RFP Bidding
Differentiating professional services bids against commodity competitor offerings.

### Government Contract Proposals
Scoring maximum technical evaluation points on federal contract tenders.
