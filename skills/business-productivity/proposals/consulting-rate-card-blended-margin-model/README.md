# Consulting Rate Card Blended Margin Model

## Description
Calculates consulting billing rate cards, target gross margins, and blended effective hourly rates. Use when pricing professional services engagements and commercial proposals.

## Purpose
Pricing professional services contracts requires factoring base developer salaries, benefits overhead, non-billable utilization rates, and target gross margin (typically 45-60%).

## When to Use
- When executing consulting rate card blended margin model in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Financial Modeling, Spreadsheets) cannot be provisioned.

## Supported Technologies
- Financial Modeling
- Spreadsheets
- Gross Margin Analysis
- Pricing

## Example Use Cases
### Client Proposal Rate Card
Publishing standard hourly and daily billing rates for enterprise consulting contracts.

### Fixed-Price Margin Safety Buffer
Ensuring fixed-scope quotes maintain at least 45% gross margin under risk buffers.
