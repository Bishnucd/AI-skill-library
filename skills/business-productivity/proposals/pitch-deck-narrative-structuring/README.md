# Pitch Deck Narrative Structuring

## Description
Structures compelling 10-12 slide venture pitch deck narratives following the problem-solution-market model. Use when pitching startups or strategic business initiatives to investors.

## Purpose
Investor pitch decks must deliver a clear, concise narrative in under three minutes. Structuring slides around the proven Sequoia model maximizes clarity, market conviction, and investor interest.

## When to Use
- When executing pitch deck narrative structuring in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Markdown, Presentation Frameworks) cannot be provisioned.

## Supported Technologies
- Markdown
- Presentation Frameworks
- Financial Modeling
- Visual Design

## Example Use Cases
### Seed & Series A Fundraising
Crafting pitch materials for venture capital partner meetings.

### Corporate Innovation Pitch
Securing internal executive sponsorship and budget for new product incubation.
