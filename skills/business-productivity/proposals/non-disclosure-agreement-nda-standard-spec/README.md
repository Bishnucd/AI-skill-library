# Non Disclosure Agreement Nda Standard Spec

## Description
Structures mutual and unilateral Non-Disclosure Agreements (NDAs) with standard confidentiality exclusions and term limits. Use when exchanging proprietary technical and business information.

## Purpose
Before sharing proprietary source code or roadmap data, companies execute NDAs. Standard agreements define confidential information, required standard of care, term limits, and standard exclusions.

## When to Use
- When executing non disclosure agreement nda standard spec in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Mutual NDA, Contracting) cannot be provisioned.

## Supported Technologies
- Mutual NDA
- Contracting
- Legal Standards
- Markdown

## Example Use Cases
### Commercial Partnership Exploration
Safeguarding proprietary product roadmaps during initial partner exploratory meetings.

### Vendor Capability Vetting
Protecting company technical architecture details before sharing with external contractors.

## Usage Instructions
1. Review the operational workflow defined in `SKILL.md`.
2. Ensure runtime dependencies (Mutual NDA) are configured in the host environment.
3. Execute the workflow steps sequentially, validating intermediate outputs.
4. Verify the final generated artifact against declared acceptance criteria.
