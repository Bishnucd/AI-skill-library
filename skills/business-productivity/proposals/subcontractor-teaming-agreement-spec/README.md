# Subcontractor Teaming Agreement Spec

## Description
Drafts teaming agreements and non-disclosure terms between prime contractors and specialized subcontractors. Use when forming consortium bids for enterprise and government tenders.

## Purpose
Complex tenders require partnering with specialized vendor subcontractors. A teaming agreement establishes bid responsibilities, work-share percentages, exclusivity, and NDA protection.

## When to Use
- When executing subcontractor teaming agreement spec in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Teaming Agreements, Legal Standards) cannot be provisioned.

## Supported Technologies
- Teaming Agreements
- Legal Standards
- Contracting
- Markdown

## Example Use Cases
### Joint Venture Tender Bidding
Teaming with boutique cloud security consultancies to bid on major bank tenders.

### Prime Contractor Teaming
Locking in exclusive subcontractor pricing before submitting competitive proposals.
