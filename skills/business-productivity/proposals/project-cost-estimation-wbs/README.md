# Project Cost Estimation Wbs

## Description
Calculates bottom-up software project cost estimates using Work Breakdown Structures (WBS) and three-point estimation. Use when scoping engineering budgets and client commercial quotes.

## Purpose
Accurate project estimation balances optimism and risk. Decomposing deliverables into a granular Work Breakdown Structure (WBS) and applying PERT three-point estimates prevents budget overruns.

## When to Use
- When executing project cost estimation wbs in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (Spreadsheets / CSV, PERT Estimation) cannot be provisioned.

## Supported Technologies
- Spreadsheets / CSV
- PERT Estimation
- Markdown
- Python

## Example Use Cases
### Client Proposal Budgeting
Providing fixed-price or capped time-and-materials quotes for enterprise contracts.

### Internal Capex Budgeting
Forecasting engineering headcount and cloud infrastructure budgets for new initiatives.

## Usage Instructions
1. Review the operational workflow defined in `SKILL.md`.
2. Ensure runtime dependencies (Spreadsheets / CSV) are configured in the host environment.
3. Execute the workflow steps sequentially, validating intermediate outputs.
4. Verify the final generated artifact against declared acceptance criteria.
