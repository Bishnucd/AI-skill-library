# Security Questionnaire Response Accelerator

## Description
Compiles and indexes standardized, pre-approved answers for customer vendor security questionnaires (CAIQ, VSA). Use when rapidly completing enterprise security questionnaires.

## Purpose
Enterprise deals stall waiting for infosec questionnaires. Maintaining a centralized library of pre-approved responses for encryption, access control, and disaster recovery speeds up deal cycles.

## When to Use
- When executing security questionnaire response accelerator in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (CSA CAIQ v4, Vendor Security Assessment (VSA)) cannot be provisioned.

## Supported Technologies
- CSA CAIQ v4
- Vendor Security Assessment (VSA)
- Knowledge Base
- Markdown

## Example Use Cases
### Sales Cycle Acceleration
Slashing security questionnaire turnaround time from 3 weeks down to 2 days.

### Security Answer Consistency
Preventing sales reps from making inaccurate technical security promises to prospects.

## Usage Instructions
1. Review the operational workflow defined in `SKILL.md`.
2. Ensure runtime dependencies (CSA CAIQ v4) are configured in the host environment.
3. Execute the workflow steps sequentially, validating intermediate outputs.
4. Verify the final generated artifact against declared acceptance criteria.
