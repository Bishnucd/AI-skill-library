# Gdpr Data Protection Impact Assessment

## Description
Authors Data Protection Impact Assessments (DPIA) evaluating privacy risks under EU GDPR Article 35. Use when launching new products or features processing personal consumer data.

## Purpose
GDPR mandates a formal DPIA when data processing is likely to result in a high risk to individuals. The assessment describes processing flows, evaluates necessity, and documents mitigation measures.

## When to Use
- When executing gdpr data protection impact assessment in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (EU GDPR, DPIA) cannot be provisioned.

## Supported Technologies
- EU GDPR
- DPIA
- Data Privacy
- Markdown

## Example Use Cases
### AI Feature Privacy Clearance
Assessing personal data implications before training models on customer support tickets.

### Regulatory Compliance Filing
Fulfilling European Data Protection Board documentation requirements.
