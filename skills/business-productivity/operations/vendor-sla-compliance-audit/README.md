# Vendor Sla Compliance Audit

## Description
Audits third-party SaaS and cloud vendor SLA compliance, uptime statistics, and contractual credits. Use when evaluating vendor contract performance and negotiating service renewals.

## Purpose
Enterprises spend millions on SaaS vendors without verifying SLA guarantees. Auditing vendor availability metrics, incident histories, and support ticket response times recovers contractual credits.

## When to Use
- When executing vendor sla compliance audit in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (SQL, Spreadsheets) cannot be provisioned.

## Supported Technologies
- SQL
- Spreadsheets
- REST APIs
- Markdown

## Example Use Cases
### Annual Vendor Review
Auditing SaaS vendor performance before contract renewal negotiations.

### SLA Credit Recovery
Filing automated credit claims following major cloud provider downtime.
