# Asset Inventory Hardware Software Audit

## Description
Constructs automated IT asset inventory audits across physical hardware, cloud instances, and software licenses. Use when maintaining CIS Control 1 & 2 asset management compliance.

## Purpose
You cannot secure what you do not know exists. CIS Controls 1 & 2 mandate maintaining actively updated inventories of all enterprise hardware devices and authorized software packages.

## When to Use
- When executing asset inventory hardware software audit in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (CIS Controls, Asset Management) cannot be provisioned.

## Supported Technologies
- CIS Controls
- Asset Management
- JSON / CSV
- ITIL

## Example Use Cases
### Annual IT Asset Reconciliation
Reconciling corporate laptop lease inventories with Active Directory active device records.

### Cybersecurity Insurance Audit
Proving 100% endpoint disk encryption coverage for cybersecurity insurance underwriters.

## Usage Instructions
1. Review the operational workflow defined in `SKILL.md`.
2. Ensure runtime dependencies (CIS Controls) are configured in the host environment.
3. Execute the workflow steps sequentially, validating intermediate outputs.
4. Verify the final generated artifact against declared acceptance criteria.
