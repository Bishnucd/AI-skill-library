# Soc2 Type 2 Readiness Matrix

## Description
Tracks AICPA Trust Services Criteria (Security, Availability, Confidentiality) evidence for SOC 2 audits. Use when preparing B2B SaaS companies for SOC 2 Type II audit examinations.

## Purpose
SOC 2 Type II audits verify that security controls operated effectively over an observation window (typically 3-12 months). A readiness matrix aligns policies with automated evidence collection.

## When to Use
- When executing soc2 type 2 readiness matrix in production workflows.
- Use when structured standards, deterministic outputs, and error handling are required.

## When NOT to Use
- Ad-hoc, unstructured exploratory tasks where formal workflows add unnecessary overhead.
- Environments where required dependencies (SOC 2 Type II, AICPA Criteria) cannot be provisioned.

## Supported Technologies
- SOC 2 Type II
- AICPA Criteria
- Vanta / Drata
- Markdown

## Example Use Cases
### Enterprise Sales Enablement
Unlocking Fortune 500 procurement deals by producing a clean SOC 2 Type II report.

### Continuous Compliance Monitoring
Preventing compliance drift between annual audit observation periods.

## Usage Instructions
1. Review the operational workflow defined in `SKILL.md`.
2. Ensure runtime dependencies (SOC 2 Type II) are configured in the host environment.
3. Execute the workflow steps sequentially, validating intermediate outputs.
4. Verify the final generated artifact against declared acceptance criteria.
